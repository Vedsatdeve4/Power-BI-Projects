# HR Analytics Dashboard with Power BI
An end-to-end HR analytics solution for Atlas Labs to track employee metrics, attrition patterns, and performance trends.

## 📊 Dashboard Overview
**Four interactive report pages:**
1. **Overview** - Hiring trends and department-wise employee distribution
2. **Demographics** - Diversity metrics (age, gender, ethnicity)
3. **Performance Tracker** - Individual employee review history
4. **Attrition Analysis** - Turnover drivers and risk factors

## 🔍 Key Insights
- **Attrition Rate:** 16.1% with highest turnover in Technology QA roles
- **Demographics:** 
  - 2.7% more female employees than male
  - 8.5% non-binary workforce
  - White employees have highest average salary
- **Age Distribution:** Majority (20-29 years old)

## 🛠️ Technical Implementation
### Data Pipeline
1. **Data Loading**
   - Imported multiple CSV datasets
   - Verified/updated auto-assigned data types

2. **Data Modeling**
   - Created dedicated date dimension table
   - Established star schema relationships
